# Migrations

Version: 1.0.0. Read this when code written for fluent_bar does not compile after an update, or
when the analyzer reports a deprecated member of fluent_bar.

Every renamed or removed public member is listed here. Its old name stays in the code with
`@Deprecated('Use <new name> instead')` for at least one minor version before it is removed, so
the analyzer points at every place to change.

To migrate: search the code for the text in the "Search for" column and rewrite each match as
shown in "Before → After". Use the new name in new code, never the deprecated one.

|---|---|---|---|---|---|
